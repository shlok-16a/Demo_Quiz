# Demo Quiz

Static 5-question cricket quiz. No login, no API, no Arena session.

## Flow

1. **Intro** — title, rules, scoring (`+10` correct / `-5` wrong / leftover seconds as speed bonus)
2. **Countdown** — 5 seconds, then play
3. **Quiz** — 5 questions, 10 seconds each
4. **Result** — score, correct / wrong / skipped, speed bonus, time taken

## Run

Open `index.html` in a browser, or:

```bash
npx --yes serve -p 5500
```
